# ManiarTech — Marketing & Collateral Workspace

Single home for everything we share outward: sales presentations, the prospectus booklet, social
media, print pieces, and promotional assets. Everything here pulls from one source of truth —
[`brand/brand-guide.md`](brand/brand-guide.md) — so every asset stays on-brand, on-message, and
honest (Governing Rule #1).

> **Not part of the website build.** This directory is intentionally outside the Taj Mahal modules
> (underscore-prefixed, like `_ia/` and `_inbox/`), so it is never rendered or published by mistake.

## Structure

| Folder | What lives here |
|---|---|
| [`brand/`](brand/) | **Read first.** Brand guide: palette, type, logo, voice, positioning, verified facts, honesty rules, proof assets. The single source of truth. |
| [`growth/`](growth/) | **The post-launch execution system**: marketing calendar (W0-M9), sole-founder weekly routine, AI social pipeline, launch playbooks, listings/citations checklists, metrics + CAPA, verification scripts. Strategy sources: `_inbox/SEO-PLAN.md`, `_inbox/DISTRIBUTION-STRATEGY.md`. |
| [`presentations/`](presentations/) | Sales decks (pitch / meeting / leave-behind). Source `.md` outlines + built `.pptx` / PDF. |
| [`prospectus/`](prospectus/) | The high-quality prospectus booklet (designed PDF, print- and share-ready). |
| [`social/`](social/) | Social-media copy + graphics (LinkedIn, etc.). |
| [`print/`](print/) | Print collateral: one-pagers, capability sheets, business cards, brochures. |
| [`promotion/`](promotion/) | Other promotional assets (email, ads, event material). |
| `assets/` | Shared exported assets (logos, ISO badge, screenshots). Master brand images live in the theme at `themes/maniartech/assets/imgs/mt-imgs/`. |

## Content sourcing
The v2 website is the canonical content bank. Reuse and re-sequence it — do not reinvent claims:
- Positioning / voice / honesty → this workspace's brand guide + `PRESENTATION-DOCTRINE.md`.
- Services, case studies, labs/standards, About, ISO/de-risking → the live site pages.
