# Ideas

A parking place for design and content ideas for maniartech.com that are not (or not yet) in the
site. Each idea has its own folder with a README (what it is, status, how to open it, what is next).
Where an idea has a runnable page, it is a single `index.html`: double-click it.

**Runnable pages need internet** (they load Google Fonts, GSAP and three.js from CDNs). No build
step, no server.

## Aamir's standing brief (so it is not lost)

- Hero section (gear cluster) stays as is. Aamir likes the gears.
- Everything below the hero needs solid improvement: excellent visualisation that tells a visitor
  "we know our job". Concepts, vision, mission, objectives, processes, motivations.
- Quality bar: "created by a professional expert design agency". Best quality, but simple,
  continuous animation, excellent grade, for various sections of the page.
- Latest correction (2026-10-20): not too much Hollywood. Balanced like an Apple website: good
  effects that tell real things. Effects and interactions must simplify the explanation of the
  concept, never exist for their own sake. See `method-explained/README.md` for the rules.
- Discuss ideas first; no commits and no PRs unless asked. Work on a branch.
- Canon still applies: dark + mint, no `!important`, claims true and sourced, private projects stay
  labelled private, the Presentation Doctrine order (see `_inbox/PRESENTATION-DOCTRINE.md`).
