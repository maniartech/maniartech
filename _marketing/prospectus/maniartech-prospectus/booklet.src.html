06 · Labs & standards
The depth behind the work

Standards we've authored — and open source anyone can run.

Some is published and in use; some is still maturing in the open. We label honestly what's finished and what isn't — and we call these standards we've authored, never "industry standards."

Published

Internet Object

A compact, schema-first data format — over 40% smaller than minified JSON, ~30% fewer LLM tokens, with a live playground.

Publish-ready · pre-1.0

UExL

An embeddable expression engine — the only one of cel-go / expr / UExL with zero allocations on the boolean and string paths.

Research · in development

Indigo

A Go superset that compiles to clean, idiomatic Go you read in the diff — "no output is better than wrong output."

Published

signals · gotime · vault-storage

Open-source Go and TypeScript libraries — a type-safe event library, intuitive date/time (100% coverage), and browser storage with IndexedDB power.

Internal · OSS planned
