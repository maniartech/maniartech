The observer pattern, moved from runtime to compile time

the usual Go event bus
bus.On("user.created", func(v any) {
    u := v.(User)  // panics at runtime
})                 // typo in the topic: silence
→
signals — generic, in-process
sig := signals.New[User]()
sig.AddListener(func(ctx context.Context, u User) {
    // u is a User. The compiler said so.
})

In-process only — not a message broker, and not an event-driven services pattern. From the README's committed benchmark: 5.66 ns/op for a single-listener emit with zero allocations, and 93.5% test coverage — machine-specific, reproducible with go test -bench on your own checkout.
