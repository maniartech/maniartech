{% elif s.anchor == "languages" %} {% comment %} Languages shelf shows language. Indigo, from /foundry/indigo/. {% endcomment %} Specimen: Indigo, a Go superset
what you write
func load(id int) (string, error) {
    user := fetch(id)!
    tier := user.Pro ? "pro" : "free"
    return render(tier), nil
} catch {
    return "", err
}
→
the Go it compiles to
func load(id int) (string, error) {
    user, err := fetch(id)
    if err != nil {
        return "", err
    }
    tier := "free"
    if user.Pro {
        tier = "pro"
    }
    return render(tier), nil
}

Ordinary Go comes out the other side - the diff your team reviews is Go they already know.

{% elif s.anchor == "standards" %} {% comment %} Standards: Internet Object beside the JSON it replaces. {% endcomment %} Specimen: Internet Object, the same data
the JSON you send today
[
  {"name": "Alice", "age": 30},
  {"name": "Bob",   "age": 25}
]
→
Internet Object
name: string, age: int
---
~ Alice, 30
~ Bob, 25

The schema is sent once; every ~ row is validated against it as it parses. See the measured savings →

Open source

Not a category — a habit.

What we publish, we publish properly - which is why "open source" isn't a separate shelf above, but a tag on the things that actually carry a licence. Every public repository lives on our GitHub: read it, run it, or reproduce a benchmark yourself. The rest is labelled private just as plainly, because the point isn't to be admired - it's that you never have to guess which claims you can check.
