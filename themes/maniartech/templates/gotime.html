The same format string, twice

standard Go — the reference-time layout
time.Now().Format("2006-01-02 15:04:05")
// 2006 means yyyy, 01 the month, 02 the
// day, 15 the hour, 04 minute, 05 second
→
gotime — NITES specifiers
gotime.Format(time.Now(), "yyyy-mm-dd hh:ii:ss")
// the format string says what it means:
// year, month, day, hour, minute, second

Two maturities this page keeps apart: the library is stable and tagged (MIT, v2.0.4, zero dependencies), while NITES — the notation itself — is still research-stage. gotime is its reference implementation, not a ratified standard.
