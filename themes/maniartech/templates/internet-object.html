name: string, age: int
---
~ Alice, 30
~ Bob, 25
~ Carol, 28

The keys JSON repeats are exactly the characters Internet Object deletes — the schema line above the --- carries them once. 22% smaller at three records, and the header is a fixed cost, so the margin grows with every record after it. Open this exact document in the playground →
