# Home scene concepts (first prototype)

Four interactive SVG scenes that visualise the Keystone idea for the Home page. **Open
`index.html`** (needs internet for the font only).

**Verdict (Aamir, 2026-10-20): too basic.** They are kept because the narrative and the scene list
are sound; the execution is what must reach the `keystone-film` standard.

## The scenes

1. **A system that stands on its own** (vision and mission). Department stones assemble into an
   arch, the keystone drops in, the scaffolding falls away. Draft Vision and Mission lines sit
   beside it for Aamir to edit.
2. **Three quiet killers** (the problem). Supervision cost, human bias, single point of
   dependency. "Knowledge in people" versus "Knowledge in the system", with **Remove the person**:
   work stalls in the first, continues in the second.
3. **The Keystone Method in five stages.** Survey, Document, Design, Set the Keystone, Bear Load.
   Each has its own mini-scene. Stage text follows the canon (`_inbox/PROJECT-CANON.md`, section 4).
4. **How a change travels.** Decision written down, build, senior review, checks, hand-off; each
   gate opens a sample artifact. The artifacts are generic stand-ins, not real project records.

`concept-board.md` is the written plan: spine idea, what each section shows, what is still needed
from Aamir, guardrails, and a suggested build order.
